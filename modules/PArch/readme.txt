Идея в том, чтобы удобно переносить файлы в виде .py - фактически просто способ собрать файл в .py для удобной распаковки простым открытием через Python. Однако не гарантируется сжатие файла - только удобный перенос в виде одного .py файла.

Идея из: https://github.com/MichiTheCat-RedStar/Project-AM/tree/main/old/AnonizerTea/PArch


Документация:

main.py показывает как работает lib/parch.py

Сам же parch.py можно запустить в интерактивном режиме (python parch.py) или в виде части конвейера как:

python parch.py <путь_до_файла> > <имя>.py

В рамках библиотеки - это функиция PArch(path:str), где в качестве path задаётся путь до файла и возвращает Python-код
