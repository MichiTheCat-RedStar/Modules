## Модули

**Модули - это репозиторий для модулей.**

Зачем выносить каждый модуль в отдельный репозиторий, если они не имеют большого размера, важности или чего-то ещё? В общем, теперь есть отдельный репозиторий для модулей, которые я бы хотел использовать чаще, чем то, что в отдельных репозиториях.
